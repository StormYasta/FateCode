# CRUD docente de desafios

Professores e administradores acessam `/teacher/challenges` para criar, editar e excluir desafios internos.

A tela reutiliza os endpoints existentes de `/api/challenges` e permite gerenciar título, slug, descrição, dificuldade, linguagem base, XP, tags, código inicial e testes públicos/ocultos em JSON.

O importador do Codewars permanece separado para desafios externos.
